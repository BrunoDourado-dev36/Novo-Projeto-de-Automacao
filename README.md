# 🤖 Novo Projeto de Automação

Projeto desenvolvido em **Python** com foco em automação de processos e análise de informações.

Nesta versão, o projeto foi organizado em **células de execução**, permitindo visualizar e executar cada etapa do processo de forma mais clara e organizada.

## 🚀 Sobre o projeto

O projeto utiliza Python para automatizar tarefas repetitivas e trabalhar com os dados diretamente durante a execução.

A automação combina interação com o sistema através do **PyAutoGUI** e análise/manipulação de dados utilizando **Pandas**.

## 🛠️ Tecnologias utilizadas

* **Python**
* **Pandas**
* **PyAutoGUI**
* **Jupyter Notebook**

## ⚙️ Funcionamento

O projeto é dividido em diferentes células, separando as etapas do processo e facilitando a visualização do código.

Entre as principais etapas estão:

1. Importação das bibliotecas necessárias;
2. Preparação e análise dos dados;
3. Execução das ações de automação;
4. Interação com o sistema através do PyAutoGUI;
5. Processamento das informações;
6. Execução do processo de forma automatizada.

## 🎯 Objetivo

O objetivo do projeto é aplicar Python na **automação de tarefas repetitivas**, tornando o processo mais organizado e reduzindo a necessidade de execução manual.

O projeto também foi desenvolvido como prática de:

* Lógica de programação;
* Manipulação e análise de dados;
* Automação de processos;
* Utilização de bibliotecas Python;
* Organização de código;
* Execução de código em células.

## 📚 Aprendizados

Durante o desenvolvimento, foram praticados conceitos como:

* Utilização do **Pandas** para análise e manipulação de dados;
* Automação de tarefas com **PyAutoGUI**;
* Organização de um projeto em etapas;
* Execução de código utilizando células;
* Integração entre análise de dados e automação.

## ⚠️ Observação

Este projeto foi desenvolvido para **fins de estudo e prática**, demonstrando como Python pode ser utilizado para automatizar processos e trabalhar com dados.

A execução da automação pode depender da estrutura do sistema e da interface utilizada.
